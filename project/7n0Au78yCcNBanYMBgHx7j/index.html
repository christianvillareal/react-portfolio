Project Overview

Riverbend Ivanhoe is a premium luxury residential apartment development situated in one of Melbourne's most historic and leafy suburbs, operating as a flagship location under the elite Norus project umbrella. The development delivers high-end boutique living spaces that balance sophisticated inner-city architectural design with serene, natural riverside surroundings.

The technical scope of this task involved developing a dedicated, conversion-optimized sub-location landing page within the HubSpot CMS platform. To capture high-intent property buyers, the static HTML mockup was converted into a flexible, fully responsive HubSpot template. Because standard drag-and-drop mechanics cannot support micro-interactions natively, custom modules were engineered with raw HTML/CSS and interactive JavaScript layers. This approach allows non-technical marketing managers to update specific property details while preserving a premium user experience.

🎯 Challenge & Strategy

The core challenge lay in adapting a complex, deeply informational real estate asset pipeline into an intuitive, modular browsing experience. Unlike broad brand pages, a specific development landing page must simultaneously showcase architectural concepts, raw floor plans, lifestyle community markers, and real-time physical construction updates without causing layout fragmentation or slow load speeds.

The development strategy utilized a "Location & Validation" narrative framework to guide high-net-worth buyers down the funnel:

  • The Atmospheric Introduction: The page opens with an immersive, wide-angle streetscape render of the development (Riverbend Ivanhoe) layered with a minimalist heading and clean interactive action paths (VIEW FEATURES / ENQUIRE).

  • The Spatial Narrative Split: The upper funnel details the physical property interiors using an alternating two-column grid layout (A Refined Interior Aesthetic, The Heart of the Home, Elevated, and Indoor-Outdoor Harmony). Custom CSS transitions reveal content elegantly as the user scrolls.

  • The Interactive Choice & Floor Plan Matrix: The mid-funnel transitions from abstract lifestyle imagery to actionable data. A structural residence selector leads into an "Apartment of the Week" feature block, pairing a data sheet with a crisp, high-resolution architectural blueprint layout.

  • The Empirical Verification Hub: To prove neighborhood value and physical progress, the lower funnel integrates a nine-quadrant community lifestyle grid, a location map, and a live "Project On Track" construction status module featuring aerial drone photography.

🛠️ Technical Implementation & Custom Engineering

✅ Custom HubL-Driven Spatial Split Modules

To achieve the alternating horizontal text-and-image rows under sections like A Refined Interior Aesthetic, custom HubSpot modules were coded using HubL (HubSpot Markup Language) fields. This custom setup enables smooth image-to-text alignment across all screen resolutions, bypassing the restrictive constraints of HubSpot's default layout styles.

✅ JavaScript Floor Plan & Residence Selectors

The residential discovery section (Choose Your Residence) and the floor plan viewport utilize a custom JavaScript interface. Lightweight scripts handle active toggle states smoothly, allowing buyers to cycle through options or inspect detailed blueprint files without forcing full page reloads.

✅ Asymmetric Grid Layouts for Community & Construction Tracking

The lifestyle section (The Best of Both Worlds) features a 3x3 layout block displaying local cafes, parks, and amenities, paired with a custom aerial development layout block (Project On Track). These components are written in clean HTML and styled with explicit CSS grid rules to prevent layout shifting when dynamic imagery loads into the browser.

✅ Advanced CSS Typography & Overlay Control

To preserve the luxury editorial identity, exact letter-spacing, line-heights, and font rules were injected directly into the template's stylesheet. Custom CSS styling ensures that translucent textual elements, like the serif quote block ("Riverbend Ivanhoe is the definition of modern living..."), maintain absolute contrast and alignment over background asset renders on mobile viewports.

✅ Integrated High-Volume HubSpot Lead Form

The customer journey concludes with a crisp, dual-column lead capture container (Register Your Interest). The native HubSpot form fields were completely customized with custom CSS, skinning standard input borders into a sleek, minimalist style that guides users cleanly to the solid dark-mode SUBMIT REGISTRATION call-to-action button.
