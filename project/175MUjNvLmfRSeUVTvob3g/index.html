Project Overview

Geftshop is a modern, full‐stack e-commerce platform specializing in curated, thrifted (ukay) maxi dresses. Designed and built entirely as an independent project, I handled the complete product lifecycle—spanning UI/UX design, frontend engineering, and backend development.

The platform allows customers to seamlessly browse products, manage their shopping carts, place orders, and choose preferred payment methods (Debit Card or GCash). It also features a robust admin dashboard to manage products, monitor live inventory, process orders, and track sales performance. Tailored to the unique nature of thrifted fashion, shipping costs are dynamically calculated per order (notifying customers via automated emails), and a strict refund policy is enforced only for damaged items.

The entire system is fully secure, production-ready, and highly responsive across both desktop and mobile devices.

Core Responsibilities & Contributions

  • UI/UX & Product Design: Crafted the end-to-end visual identity, layout architecture, and user journeys. Focused on building an elegant, minimalist aesthetic suited for a boutique fashion brand while prioritizing an intuitive, conversion-friendly checkout flow.

  • Frontend Development: Implemented a highly responsive, component-driven user interface. Developed custom image-cropping tools for clean product presentation and integrated dynamic data visualization for the administrative dashboard.

  • Backend & Architecture Engineering: Engineered a lightweight, secure RESTful API to manage the product catalog, transaction records, and administrative workflows. Integrated third-party cloud storage solutions for media assets and decoupled state management for efficient cart handling.

Key Product Features

  • Smart Product Catalog: Each curated piece includes detailed attributes (name, description, price, and "On Hand / Sold Out" stock statuses).

  • Automated Sizing: Automatically calculates standard Asian Sizes (XS–4XL) based on precise manual inputs (Bust, Waist, Length).

  • Media Management: Supports up to 8 high‐quality images per product, automatically cropped to a clean 4:5 portrait aspect ratio for consistent grid alignment.

  • Serialized Cataloging: Generates an auto-incrementing, unique dressCode (starting at 1001001) serving as the primary SKU identifier.

  • Frictionless Cart & Checkout: Customers provide standard fulfillment details (name, email, phone, and address). To eliminate third-party transaction fees and accommodate fluctuating courier rates, shipping is calculated post-purchase by the administrator. Customers select their preferred payment method (Debit Card or GCash) during checkout, and the admin coordinates direct payment after confirming the order details.

  • Administrative Command Center: A powerful, secure dashboard that allows the administrator to view all transactions, filter orders by status (Pending, Approved, Shipped, Cancelled), adjust live inventory, and view deep customer insight logs. Every successfully placed order triggers real-time email notifications directly to the admin with full breakdown details.

Technical Stack & Infrastructure

Technologies & Tools

Frontend

React 19, Tailwind CSS 3, React Router DOM (HashRouter for seamless GitHub Pages routing), Swiper.js (touch-responsive carousels), Recharts (interactive dashboard analytics), React Easy Crop (client-side image processing).

Backend

Node.js, Express.js, Multer (multipart form-data handling), Cloudinary API (cloud image hosting), JSONBin (persistent cloud JSON storage for orders and catalogs), Resend API (transactional email automation).

State & Auth

React Context API (CartContext) combined with localStorage for persistent shopping sessions. Session-based administrator protection via secure localStorage tokens.

Deployment

Frontend: GitHub Pages (Static Hosting)

Backend: Render (Cloud Hosting Platform)

Media Asset Storage: Cloudinary CDN
